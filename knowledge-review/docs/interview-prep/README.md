## 如何建立真实的个人面试经历

将以下三栏保持分离：

| 栏目 | 可填写内容 | 不应填写内容 |
| --- | --- | --- |
| 项目原有实现 | 从源码和历史产物确认的机制 | “所以这些一定是我最初独立设计的” |
| 目前能解释的依据 | 手算公式、调用链、适用条件、反例 | 未做过的选型比较或主观想象的动机 |
| 亲自验证/改进 | 自己实际运行的输入、代码版本、结果、失败及复测 | 本次由Agent生成材料或执行测试就自动变成个人亲手经历 |

可以诚实说：“这个项目大量借助Coding Agent实现。我现在重点核验了……，能从……函数解释边界。关于……的历史动机没有记录，我会按……实验重新评审。”只有自己完成可复现练习后，才把“核验了”填成相应具体工作。
