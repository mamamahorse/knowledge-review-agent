# 清单直接提取 V2：实现与使用边界

首次实现：2026-10-26；当前行为更新：2026-10-28。分支：codex/outline-extraction-v2。父阶段：e947e6b（任务识别与持久澄清）。

## 算法与预算

网页“学习清单”增加 V1/V2 选择，默认仍为 V1。API 的 algorithm 缺省为 v1；v2 显式启用新路径。无计划的旧任务继续 legacy，plan.version=1 继续原概述树，version=2 使用 outline_v2.run_direct。其他版本拒绝；历史任务不改写算法。

V2 复用 Source.document/ContentBlock、block_chunk、真实表头与邻近条件引用，按来源顺序贪心合并结构单元，并针对完整消息、Schema、输出预留和两种结构化协议检查容量。没有固定80行窗口，也不调用窗口/章节/文档概述模型。不同来源分别规划，章节路径随实际片段交付。

V2 默认应用总预算131072，可在网页修改或以 OUTLINE_V2_CONTEXT_TOKENS 配置；API context_tokens 按任务传入。该预算连同输出预留、安全余量保存到 plan.generation_budget，恢复使用保存值；_request_structured 将预算传入 request_structured。2026-10-28 按用户要求，全局 GenerationBudget 默认值也改为上下文131072、输出12288、安全余量2048，V1/聊天采用相同默认值；显式环境配置仍优先。默认输入可用预算为116736，包含协议与消息估计开销，并非正文额度。仍采用现有UTF-8字节及协议余量保守估算，不是精确模型token计数。此次没有修改私人.env，也没有重启现有进程。

预算没有写死32k；显式配置可保留32768/4096等历史对照。当前 V2 proposals 的8项和 criteria 的4条均为软阈值，不再是 maxItems。模型应检查重复与能力是否独立，仅合并等价目标/标准，不能为满足数量删除必要条件；同一能力确需五条标准可全部保留，九个独立目标也可在输出空间足够时完整返回。程序记录目标数量、是否达到八条提示值，以及超过四条标准的组织提示，不因这些数量报错或另发一次强制整理请求。语义组织由本次生成中的提示和后续审核约束，程序不能仅凭数量证明能力一致。

动态拆分依据为原文内 omission_risk、输出截断或请求预算不足；达到八条本身不触发拆分，也不单独产生覆盖风险。资料外 missing_context 仍只记录。拆分深度4和调用额度200继续作为资源边界；触顶有遗漏时保留有效候选与覆盖风险，截断无法拆分时失败，不接收半截结果。真实实验仍须采用更小的预先约定调用总额。

2026-10-27 已将原模型字段coverage_risk拆为omission_risk与missing_context。2026-10-28 软阈值修订进一步更新策略为direct-structure-v3-soft-targets，并保存新Schema摘要。旧策略或Schema任务恢复会暂停，需新建任务；旧候选、预算与诊断不改写。coverage_risk仍可作为程序生成的未解决原文遗漏诊断，不是模型输出字段。历史实验的8项饱和拆分及4096输出预算属于旧算法记录，不能用此次代码静默续跑旧实验，也不能把旧成绩当成新方案效果。

## 证据、失败与恢复

窗口明确 primary_ranges 和 support_ranges。真实表头、单位/脚注按原文分别发送，不能伪装连续行；每个候选须有主要范围内引用，不能仅依靠辅助原文生成目标。程序范围校验不证明语义蕴含。原文不可变，候选编辑仍不能换证据。

完整表格可装入时保留；过大表格按可验证原始数据行分组并重复真实表头。无法可靠解析的复杂表行、超宽单行和不能按完整原文行细分的段落显式未处理；图片导航不会生成目标。纯标题/空白/页面导航可无模型完成，解析问题单独展示。当前未实现字符偏移切句、跨页复杂表格重构或自动跨章节原文补读。

V2拆分在短事务中检查job状态和attempt，完整保存子批，父批转superseded；父批临时结果只存诊断，不创建正式候选，避免父子重复发布。覆盖统计只计算有效完成主范围的并集，辅助范围和父批不重复计入。达到深度上限而仍有原文遗漏时，保留经过引用校验的候选，并明确显示“覆盖待核查”；处理完成不等于知识完整。

criteria放宽同时贯通通用TargetDraft、清单TargetProposal和初次/变式/讨论出题的评分标准及criterion_indices，避免五条条件在加入计划时被下游四条上限阻塞。validate_question仍要求覆盖全部目标条件，映射长度与评分标准一致；漏掉第五条仍拒绝。独立教学追问ExerciseDraft的2–4条上限不变，该追问本来就不重新定义长期目标。V1的局部4目标和全文6目标数量契约未改。

沿用原作业锁、request_id、快照指纹、暂停/继续和真实Future槽位释放。算法/预算改变不能复用同一提交标识；计划保存模型名称和端点哈希，恢复时模型变化会停止而不混用。已完成候选不覆盖；网络调用不持有写事务。

## 诊断与成本

保存每批请求预算、耗时、调用计数、返回的模型身份和usage。失败/重试尝试保留attempts，不覆盖旧耗费；父批也保留。V2显式观测调用关闭SDK隐式重试，原生Schema回退工具协议的每次显式调用均经过前置检查与额度登记。计数包括预留后被中断的调用机会，不冒充账单精确请求数。

usage未返回或在截断/传输异常中未能取得时为null。此时不能声称已取得实验总实际token或总成本；不得用估算填充真实usage。原始诊断保存在隔离实验库/业务任务库，模型隐藏推理不保存。
