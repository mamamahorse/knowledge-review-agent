# 数据库写入与只读模式

本文件是公开合成检索协议，仅以本文规则为准，不描述真实部署。每节有独立适用条件；其他文件同名字段不能替代本节证据。

## busy_ms

本合成存储层 busy_ms=1500 仅控制遇到 SQLite 写锁时最长等待毫秒数，不限制 SQL 执行时间。等待后仍无法取得锁，返回 WRITE_BUSY，保留调用方操作身份以便重试。等待不是把失败事务提交成功，也不会把正文截短。读取未遇写锁时不消耗这项额度；这是协议配置，不是所有 SQLite 应用的默认值。

## revision_compare

revision_compare 在 BEGIN IMMEDIATE 内读取当前 revision，只有与 expected_revision 相等才更新正文并加一。相等才可提交；不等返回 STALE_EDIT，保留已发布的新正文。不能在事务外比较一次就认为写入安全，网络请求也不得在持有此写事务时等待。

## read_only

read_only=true 时查询与历史快照展示仍允许；新增登记、修改标签和计划加入全部拒绝，返回 STORE_READ_ONLY。只读模式不是仅隐藏网页按钮，服务端所有写入口都须检查。评分预览可计算但不得保存学习事件或修改复习日期；成功预览不能作为一次已完成复习的证据。

## 事务与外部调用

write_then_generate 先用短事务保存用户输入及 pending 状态，然后释放写锁调用模型；模型返回后另开短事务复查身份与版本，再发布回复。模型失败保留输入和 failed 状态；重试复用原轮次。不得把数据库事务跨越整个外部生成过程，外部服务无法与本地 SQLite 一起回滚。

## query_ms

query_ms 是查询性能告警阈值，超出只记录告警而不中止 SQL。它不控制写锁等待，也不能代替 busy_ms 或代表成功提交。 本节独立描述这个辅助功能，名称相似不代表与其他协议具有相同身份、单位或权限。不能用观察值推断未提供的业务条件，未写的配置应视为信息不足。

## 连接池

pool_size=4 表示只读连接上限，不意味着允许四个同时写事务。连接等待计时独立于 SQL 查询耗时，连接归还不代表事务提交。 本节独立描述这个辅助功能，名称相似不代表与其他协议具有相同身份、单位或权限。不能用观察值推断未提供的业务条件，未写的配置应视为信息不足。

## 备份

backup_snapshot 复制一致的数据库快照供恢复演练。备份本身不清除 failed 轮次，也不把只读模式切换成可写模式。 本节独立描述这个辅助功能，名称相似不代表与其他协议具有相同身份、单位或权限。不能用观察值推断未提供的业务条件，未写的配置应视为信息不足。

## 日志轮转

rotate_log 按字节大小轮转运行日志。运行日志不是学习事件表，删除日志不会回滚已提交的复习记录，也不会释放 SQLite 写锁。 本节独立描述这个辅助功能，名称相似不代表与其他协议具有相同身份、单位或权限。不能用观察值推断未提供的业务条件，未写的配置应视为信息不足。
