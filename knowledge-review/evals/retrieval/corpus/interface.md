# 检索评测合成资料：interface.md

以下规则用于本评测；条件与范围属于证据的一部分，不能据此推断真实部署。

## 界面 ACK 按钮

合成桌面程序的 ACK 按钮表示用户确认看过提示。点击后只更新界面的已读状态，不描述 TCP 报文确认号，不表示收到某段网络字节。界面字段和协议缩写文字相同也不共享语义。按本程序约定，按钮不触发数据库学习评分或自动加入计划。

## 图形窗口

本程序的窗口是展示页面的矩形区域，宽度单位为像素；它与接收方通告的 TCP 数据窗口没有对应关系。调整窗口大小改变排版，不改变允许读取的资料或报文序号。检索时应结合用户提到的图形界面、像素和布局等条件判断目标概念。

## 重置 RESET

界面 RESET 按钮恢复表单默认值，不发送 TCP 复位报文，也不删除服务器数据库。用户看到 RESET 文本不能据此断定 RST 包出现。重置只影响当前未保存输入；已经保存的作答和历史消息仍可读取，字段命名属于本合成程序的约定。

## 确认对话框

确认对话框用于让用户决定是否进行某项操作。确认删除与网络累计确认不是一个知识点，不能因为都出现确认二字就共享引用。对话框只是操作入口；实际是否提交取决于后端状态校验。关闭对话框不会产生复习事件或文档内容版本。

## 语言偏好

界面的中文和英语选项只规定生成回答的语言偏好，不改变原始文档语言，不翻译证据快照。不同语言表述可能表达同一查询，检索时不能只比较字符完全相同。偏好不是结构校验能保证的语义结果，本资料未提供其他语言的产品支持承诺。

## 输入草稿

表单中的未提交文字属于草稿，不应当充当用户已经完成的真实作答。保存草稿只便于刷新恢复，不更新学习目标的证据状态。界面显示操作成功与学习效果是不同层次；检索问题关于真实作答时需要找到提交和评分规则，而不是只引用草稿说明。

## 页面跳转

点击引用时应使用引用绑定的资料版本及原文位置。当前文件已替换时，旧引用应该显示旧摘录，不能跳到新文件相同行冒充证据。本文说的是合成阅读器行为，不给出通用浏览器安全规则；页面 URL 本身也不是原文的证据标注。

## 列表筛选

按标题筛选只改变显示列表，不撤销资料或聊天的记忆资格。归档从常用列表收起，删除才是资格撤销，两者不能混同。检索返回的记录必须经过后端资格检查；客户端隐藏一个列表项，不足以证明模型无法再读取它。
