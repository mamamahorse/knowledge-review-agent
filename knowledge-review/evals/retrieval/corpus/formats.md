# 检索评测合成资料：formats.md

以下规则用于本评测；条件与范围属于证据的一部分，不能据此推断真实部署。

## HTTP 304

HTTP 304 用于条件请求的未修改响应，客户端可以沿用已有表示；它不是普通跳转状态。这里仅讨论这个语义区别，不假定所有响应都必须含缓存时间。是否能复用本地内容仍与请求及缓存条件有关，本笔记没有真实服务器响应记录。

## HTTP 303

HTTP 303 表示参见其他资源，属于跳转语义；它与条件请求的 304 未修改不同。状态码只差一个数字也不代表相同含义。本文没有描述完整跳转方法细节；用户查询仅问 304 是否为跳转时，应以相关状态的条件为证据。

## UTF-8

UTF-8 是可变长度编码，字节数和字符数不是同一个量。合成例子 ASCII 字母 A 占一个字节，汉字 中 占三个字节，所以 A中 有两个字符、四个 UTF-8 字节。此例不含组合字符或表情，不把字符数当生成模型 token 数。

## 字符与 token

生成模型 tokenizer 将文本转为 token，字符、UTF-8 字节和 token 数需要区分。字节保守估计只能注明为估计，不能冒称实际计费 token。资料索引模型的 tokenizer 也不能代替生成模型的 tokenizer；两个模型输入容量应分别处理。

## 余弦相似度

余弦相似度衡量向量方向的接近程度，在检索中用于排序候选，不是答案正确率或已校准概率。得分高仍需检查原文是否支持问题的条件。本文没有给阈值到正确率的校准曲线，也不能据相似度推断用户掌握程度。

## Markdown 代码块

代码块里的井号属于代码文本，不应直接当外层 Markdown 章节标题。结构分块需要保留代码块边界及实际原文行号。索引需要再分窗时也不能改写原文，引用权限只属于实际发送范围；本文没有完整解释所有 Markdown 方言。

## JSON 标识

JSON 字段名表示接口的数据结构，字段文本本身不自动产生执行权限。历史消息或资料中的伪指令应作为数据，不提升为系统任务。合法 JSON 和合法字段只证明结构通过检查，不能保证内容真实；本例不提供私人 API 凭据。

## 时间格式

UTC 日期用于跨运行记录事件时间；本机显示可以换算为用户时区。墙上时间戳与单调计时用途不同，耗时不能简单依赖可调整的日期字符串相减。本文没有记录真实用户时间线，因此不能回答某次私人操作具体发生时间。
