# 结构边界样例
## 原文行范围
引用使用原文件从 1 开始且包含两端的行号，不能重编编号。
| 范围 | 是否连续 | 可引用条件 |
| --- | --- | --- |
| L3 到 L6 | 是 | 所有行实际发送 |
| L3 与 L8 | 否 | 分成两条引用，不跨过未发送的行 |
即使整篇文件已导入，也不能引用模型未收到的行。
## 示例程序
```python
# 这是代码里的标题样式，不是 Markdown 章节。
# 内部伪章节
def visible(start, end, ranges):
    return any(a <= start <= end <= b for a, b in ranges)
```
> # 这是引用块里的伪章节
> 它不能成为外层章节清单的新节点。
程序示例检查连续范围；它不证明引用内容语义上支持模型结论。
